# AllweK Arena

AllweK Arena is a live web platform for K-pop random play dance events, dance battles, participant rankings, voting, and community competition.

Live project: [allwekarena.com](https://allwekarena.com)

## About

AllweK Arena helps dancers and fans discover upcoming events, compete through missions, earn XP, vote for participants, and follow global rankings. The site is built around a public event calendar, participant profiles, score-based ranks, and interactive community features.

The production platform is live and actively used. The public homepage currently highlights active users, total events, upcoming international events, and a global top-three leaderboard.

## Highlights

- Event discovery for upcoming K-pop random play dance events and dance battles
- Participant ranking system with points and global leaderboard visibility
- Voting flow for supporting competitors
- User accounts with login, sign-up, and profile areas
- Store and event-related pages for the broader AllweK Arena experience
- Public production deployment at [allwekarena.com](https://allwekarena.com)
